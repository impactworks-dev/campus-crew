# Syllabus Escape Room

Text agent that reads a student's syllabi, sends the 3 moves that matter each week, warns before big deadlines, and does final-grade math. Helps students learn; never writes their work.

- Launch: Finals Sprint, Nov 30 to Dec 10, 2026. Big push on Reading Day, Dec 3.
- Pricing (concept): Free for 1 class · $5.99/mo Escape Pass · $9 Finals Week (3 weeks).
- Signature: combination-lock grade calculator (A/B/C tumblers).

Files: `index.html` + `assets/` (floater.webp, still.webp, grain.png).
