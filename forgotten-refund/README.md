# The Forgotten Refund

Text agent that finds forgotten subscriptions, price hikes and double charges, cancels with the student's yes, and chases refunds. Read-only; never moves money.

- Launch: Trial Purge, Jan 11 to Feb 5, 2027. Roommates push Feb 15 to Mar 14.
- Pricing (concept): Free first scan · $3.99/mo Refund Pro · $7.99/mo Roommates (up to 4).
- Signature: leak finder that prints a live receipt.

Files: `index.html` + `assets/` (floater.webp, still.webp, grain.png).
