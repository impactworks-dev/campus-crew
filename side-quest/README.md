# Side Quest

Text agent that turns "we're bored" into a doable mini-adventure for a friend group, sized to budget, time and vibe, with XP and floor-vs-floor seasons.

- Launch: teaser Dec 10, 2026; welcome-back launch Jan 8, 2027; Campus Clash season Feb 1 to Apr 28.
- Pricing (concept): Free (1 quest/week) · $4.99/mo Squad Pass · $29/mo Campus Clash per floor or club.
- Signature: d20 quest roller (16 quests, rarity by roll).

Files: `index.html` + `assets/` (floater.webp, still.webp, grain.png).
